# طريقك أمان 🛣️ | Tareeqak Aman

تطبيق موبايل للإبلاغ عن مشاكل الطرق في مصر (حفر، مطبات، إنارة معطلة، مياه متراكمة، بالوعات مكشوفة) — مشروع التخرج Project 1، قسم أجهزة وحاسبات، Modern Academy.

**التقنيات:** Expo (React Native) + Firebase (Firestore + تسجيل دخول بالبريد) + خرائط OpenStreetMap/Leaflet (مجانية ١٠٠٪، من غير أي مفاتيح Google) + Cloudinary لرفع الصور (اختياري ومجاني) + خط Cairo العربي.

**المميزات:** بلاغ بصورة وموقع على الخريطة • رقم مرجعي لكل بلاغ وخط زمني لحالته • خريطة تفاعلية ملوّنة حسب الحالة • تسجيل دخول وإنشاء حساب (وفيه دخول كضيف) • كشف البلاغات المكررة القريبة • لوحة تحكم مشرفين بإحصائيات • شاشات تعريف أول تشغيل.

---

## ٠) المطلوب قبل ما تبدأ (تعمله مرة واحدة بس)

1. **نزّل Node.js** من https://nodejs.org — اختار نسخة LTS، واعمل Next Next Next لحد ما يخلص.
2. **نزّل تطبيق Expo Go** على موبايلك من Google Play.
3. فك ضغط فولدر المشروع في أي مكان (مثلاً على الديسكتوب).

> اتأكد إن Node اتحط صح: افتح CMD واكتب `node -v` — المفروض يطلعلك رقم نسخة.

---

## ١) تثبيت مكتبات المشروع

افتح CMD جوه فولدر المشروع (من مستكشف الملفات: Shift + كليك يمين ← "Open in Terminal" أو اكتب `cmd` في شريط العنوان) واكتب:

```
npm install
```

استنى لما يخلص (أول مرة ممكن تاخد ٣-٥ دقايق).

## ٢) إعداد Firebase (٥ دقايق — لازمة عشان البلاغات تتخزن)

1. افتح https://console.firebase.google.com وسجل دخول بحساب جوجل.
2. اضغط **Add project** (أو إنشاء مشروع).
3. اكتب اسم المشروع: `tareeqak-aman` واضغط **Continue**.
4. قفل Google Analytics (شيل العلامة) واضغط **Create project** ← **Continue**.
5. من الصفحة الرئيسية للمشروع، اضغط على أيقونة الويب **`</>`** عشان تسجل تطبيق ويب.
6. اكتب أي اسم (مثلاً `tareeqak-web`) واضغط **Register app** (متحتاجش Firebase Hosting).
7. هيظهرلك كود فيه `firebaseConfig` — **انسخ القيم الخمسة** وحطها مكان اللي في ملف:
   ```
   src/config/firebase.js
   ```
   (بدل `PASTE_API_KEY_HERE` وباقي القيم — كل قيمة مكانها)
8. من القايمة اللي على الشمال اضغط **Build ← Firestore Database**.
9. اضغط **Create database** ← اختار **Start in test mode** ← **Next** ← اختار أقرب منطقة (مثلاً `eur3`) ← **Enable**.
10. **فعّل تسجيل الدخول:** من القايمة اللي على الشمال **Build ← Authentication** ← اضغط **Get started** ← من تبويب **Sign-in method** اختار **Email/Password** ← فعّل الخيار الأول (Enable) ← **Save**.

خلاص! قاعدة البيانات وتسجيل الدخول شغالين.

> 📌 لو المشروع ده وصلك جاهز (من GitHub مثلاً)، قيم Firebase متظبطة أصلاً في `src/config/firebase.js` — بس لازم تعمل خطوتي ٩ و١٠ في مشروعك على Firebase.

> ⚠️ **مهم جدًا — القواعد (Rules):**
> - وضع test mode بيخلي القاعدة مفتوحة ٣٠ يوم بس. قبل ما يخلصوا، لازم تقفل القاعدة بقواعد زي اللي في ملف `firestore.rules` الموجود في الريبو.
> - **لو نشرت قواعد قبل كده وفيها UID بتاعك:** متعملش نشر (deploy) تاني من ملف الريبو أبد — ملف `firestore.rules` هنا فيه `PASTE_ADMIN_UID_HERE` مكان الـ UID الحقيقي، وأي نشر منه هيمسح قواعدك المضبوطة. أي تعديل للقواعد يتعمل من تبويب **Rules** في Firebase Console على طول.

## ٣) إعداد Cloudinary (اختياري — عشان صور البلاغات تترفع)

لو متظبطهاش التطبيق هيشتغل عادي، بس البلاغات هتتسجل من غير صور.

1. افتح https://cloudinary.com واعمل حساب مجاني (**Sign up for free**).
2. من الـ **Dashboard** فوق هتلاقي **Cloud name** — انسخه.
3. من ترس الإعدادات ⚙️ فوق ← تبويب **Upload** ← انزل لـ **Upload presets** ← اضغط **Add upload preset**.
4. غيّر **Signing Mode** من `Signed` لـ **`Unsigned`** (دي أهم خطوة!) واضغط **Save**.
5. انسخ اسم الـ preset اللي اتعمل.
6. افتح ملف `src/config/cloudinary.js` وحط القيمتين مكان `PASTE_CLOUD_NAME_HERE` و `PASTE_UNSIGNED_PRESET_HERE`.

## ٤) تشغيل التطبيق على موبايلك

1. في CMD جوه فولدر المشروع:
   ```
   npx expo start
   ```
2. هيظهرلك **QR code** في الترمينال.
3. **وصّل موبايلك واللابتوب على نفس شبكة الواي فاي.**
4. افتح تطبيق **Expo Go** على موبايلك ← **Scan QR code** ← امسح الكود.
5. التطبيق هيفتح على طول 🎉

> لو الـ QR مش راضي يتفتح (شبكة الجامعة مثلاً): اقفل بـ Ctrl+C وشغّل `npx expo start --tunnel` وامسح الكود الجديد.

---

## ٥) إخراج ملف APK (عشان تسطبه على أي موبايل)

1. اعمل حساب مجاني على https://expo.dev
2. نزّل أحدث نسخة من الكود: من صفحة الريبو على GitHub اضغط **Code ← Download ZIP** وفك الضغط، وبعدين افتح **CMD جوه الفولدر** الجديد.
3. ثبّت المكتبات بالظبط زي الملفات المقفولة:
   ```
   npm ci
   ```
4. قول للنظام إن مفيش git هنا (ضروري لأن النسخة ZIP من غير `.git`):
   ```
   set EAS_NO_VCS=1
   ```
5. سجّل دخولك في Expo (أول مرة بس):
   ```
   npx eas-cli login
   ```
   (هيفتح صفحة تسجل دخول فيها بحساب expo)
6. ابدأ البناء:
   ```
   npx eas-cli build --platform android --profile preview
   ```

   - أول مرة هيسألك `Generate a new Android Keystore?` — اكتب **Y** وسيبه يدير كل حاجة.
   - البناء بيحصل على سيرفرات Expo (مش على جهازك) وهياخد حوالي ١٠-١٥ دقيقة.
7. لما يخلص هيديك **لينك تحميل** — افتحه من موبايلك، نزّل ملف الـ APK وسطّبه (هيسألك تسمح بالتثبيت من مصادر خارجية — وافق، ده طبيعي لأي APK بره بلاي ستور).

> ⚠️ متشغّلش `npx eas-cli build:configure` ولا أي أمر `firebase deploy` — كل الإعدادات جاهزة في الريبو، وأي نشر للقواعد ممنوع (شوف ملحوظة القواعد فوق).

## ٦) لوحة تحكم المشرفين

- من الصفحة الرئيسية ← **المشرفين** ← الرقم السري **`2612`**.
- غيّر الرقم من ملف `src/config/admin.js`.
- من اللوحة تقدر تشوف إحصائيات، والبلاغات مرتبة بالأولوية (الخطورة العالية الأول)، وتغيّر حالة أي بلاغ (جديد ← قيد العمل ← تم الحل)، أو تحذف بلاغ.

## حصلت مشكلة؟

| المشكلة | الحل |
|---|---|
| `npm install` بيعلق | جرب `npm install --legacy-peer-deps` |
| الخريطة بيضا | اتأكد من الإنترنت (الخريطة بتحمّل من OpenStreetMap) |
| البلاغ مابيتسجلش | راجع خطوة Firebase — القيم في `src/config/firebase.js` وإن Firestore اتعمل test mode |
| الصورة مابترفعش | راجع إعدادات Cloudinary، وأهم حاجة الـ preset يكون Unsigned |
| Expo Go بيقول إصدار قديم | حدّث تطبيق Expo Go من بلاي ستور |
| `Unable to resolve module` | امسح الكاش: `npx expo start -c` |
