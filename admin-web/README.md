# لوحة تحكم المشرفين — نسخة الويب

لوحة ويب ثابتة (HTML/JS بس) بتقرا وتكتب على نفس Firestore بتاع التطبيق.

## الحماية (طبقتين)

1. **PIN 2612** — شاشة أولى خفيفة (SHA-256 hash في الكود).
2. **تسجيل دخول المشرف بـ Firebase Auth** — ده اللي بيفتح اللوحة فعلًا.
3. **قواعد Firestore** (`firestore.rules`) — البلاغات قراءة وإنشاء للكل، لكن التعديل والحذف للمستخدمين المسجلين بس. دي الطبقة الحقيقية اللي بتمنع أي حد من التلعب في الداتا من بره.

## خطوات الصبح بالظبط (من لابتوبك)

1. **فعّل تسجيل الدخول بالبريد** (لو مش متعمل): Firebase Console → اختار مشروع `tareeqak-aman-bfebc` → **Authentication** → تبويب **Sign-in method** → **Email/Password** → Enable → Save

2. **اعمل حساب المشرف**: **Authentication** → تبويب **Users** → **Add user** → اكتب بريد وكلمة سر للمشرف (احفظهم عندك — هتسجل بيهم في اللوحة وفي التطبيق)

3. افتح Terminal / PowerShell في فولدر المشروع (اللي فيه `firebase.json`) وسجّل دخولك:

   ```
   npx firebase-tools login
   ```

4. انشر اللوحة **وقواعد الأمان** مع بعض:

   ```
   npx firebase-tools deploy
   ```

5. هيظهرلك لينك زي `https://tareeqak-aman-bfebc.web.app` — افتحه، اكتب الـ PIN، سجّل دخول بحساب المشرف، وابدأ الإدارة.

## ملاحظات

- مفيش خطوة build — اللوحة ملف `index.html` واحد ثابت.
- تغيير الحالة بيكتب على Firestore بنفس شكل التطبيق (`status` + `statusHistory`) فبيظهر في التطبيق فورًا.
- **مهم**: من غير الخطوة 4 قواعد الأمان مش هتتنشر، والداتاباس هتفضل مفتوحة (وضع الاختبار). بعد النشر، التعديل/الحذف محتاج تسجيل دخول — يعني التطبيق كمستخدم عادي هيشتغل عادي (قراءة + إبلاغ)، ولوحة المشرف بس اللي محتاجة الحساب.
- لو غيّرت الـ PIN في التطبيق (`src/config/admin.js`)، حدّث `PIN_HASH` في `index.html`:
  `python3 -c "import hashlib; print(hashlib.sha256(b'NEWPIN').hexdigest())"`
