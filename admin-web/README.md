# لوحة تحكم المشرفين — نسخة الويب

لوحة ويب ثابتة (HTML/JS بس) بتقرا وتكتب على نفس Firestore بتاع التطبيق.

## الحماية (طبقتين)

1. **PIN 2612** — شاشة أولى خفيفة (SHA-256 hash في الكود).
2. **تسجيل دخول المشرف بـ Firebase Auth** — ده اللي بيفتح اللوحة فعلًا.
3. **قواعد Firestore** (`firestore.rules`) — البلاغات قراءة وإنشاء للكل، لكن التعديل والحذف لحساب المشرف **بمعرّفه (UID) تحديدًا**. أي حساب تاني، حتى لو مسجل دخوله في التطبيق، قاعدة البيانات نفسها بترفض تعديله. دي الطبقة الحقيقية اللي بتمنع أي حد من التلعب في الداتا من بره.

## خطوات الصبح بالظبط (من لابتوبك)

1. **فعّل تسجيل الدخول بالبريد** (لو مش متعمل): Firebase Console → اختار مشروع `tareeqak-aman-bfebc` → **Authentication** → تبويب **Sign-in method** → **Email/Password** → Enable → Save

2. **اعمل حساب المشرف**: **Authentication** → تبويب **Users** → **Add user** → اكتب بريد وكلمة سر للمشرف (احفظهم عندك — هتسجل بيهم في اللوحة وفي التطبيق)

3. **اربط القواعد بحساب المشرف**: من جدول **Users** انسخ قيمة عمود **User UID** بتاع الحساب اللي عملته، افتح ملف `firestore.rules` في فولدر المشروع واستبدل `PASTE_ADMIN_UID_HERE` بالمعرّف اللي نسخته، واحفظ الملف. (من غير الخطوة دي محدش هيقدر يعدّل ولا يمسح بلاغات — ولا حتى المشرف.)

4. افتح Terminal / PowerShell في فولدر المشروع (اللي فيه `firebase.json`) وسجّل دخولك:

   ```
   npx firebase-tools login
   ```

5. انشر اللوحة **وقواعد الأمان** مع بعض:

   ```
   npx firebase-tools deploy
   ```

6. هيظهرلك لينك زي `https://tareeqak-aman-bfebc.web.app` — افتحه، اكتب الـ PIN، سجّل دخول بحساب المشرف، وابدأ الإدارة.

**لو نسيت خطوة ٣ قبل النشر**: التعديل والحذف هيتقفلوا على الكل. الحل السريع من غير ترمينال: Firebase Console ← Firestore Database ← تبويب **Rules** ← حط المعرّف مكان `PASTE_ADMIN_UID_HERE` ← **Publish**.
